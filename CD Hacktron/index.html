Step 03 · The fix

Separate matched and unmatched statements.

The rewrite encodes the nearest-unmatched-if rule directly in the grammar. Every else must now complete a matching if.

Ambiguous grammar
S → if (C) S
  | if (C) S else S
  | action

Both productions can consume the same else.

→
Unambiguous grammar
S         → M | U
M (matched) → if (C) M else M | action
U (open)    → if (C) S
            | if (C) M else U

Only an unmatched statement may still wait for an else.
